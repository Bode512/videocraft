# Anuncios con VideoCraft

Usar para producir un anuncio desde material aportado por el usuario.
1. Obtener producto, audiencia, promesa demostrable, plataforma y llamada a la accion.
2. Escribir un gancho de 0 a 2 segundos, demostracion del beneficio y cierre con una sola accion.
3. Ejecutar `videocraft probe ARCHIVO` para conocer duraciones y pistas.
4. Obtener el formato con `videocraft example`. Guardar solo result como proyecto JSON.
5. Elegir planos que demuestren la promesa. Para texto, subtitulos y logos, aportar clips ya rotulados: esta version no genera overlays.
6. Leer `videocraft skills music`, seleccionar musica y ajustar duraciones.
7. Ejecutar check, render --dry-run, render y aplicar la skill quality.
No inventar testimonios ni resultados del producto. No prometer calidad 10/10 sin revisar el video.
